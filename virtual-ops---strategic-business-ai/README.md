# Virtual OPS Hub - Powered by VOPSy

The official strategic assistant and operational hub for Virtual Ops LLC.

## Features
- **AI Employee (VOPSy):** Context-aware consultant for managed and direct service tiers.
- **Smart Reconciliation:** Automated bank matching with AI-driven compliance insights.
- **LMS Academy:** Dynamically generated training modules for client onboarding.
- **Wix Integration:** One-click deployment snippet for embedding the hub into Wix sites.
- **Market Intel:** Real-time search-grounded research reports.

## Setup
1. Clone the repository.
2. Provide your `API_KEY` via environment variables.
3. Serve the `index.html` via any modern static file server.

## Technologies
- React (ESM)
- Tailwind CSS
- Google Gemini API (@google/genai)
- Vercel Deployment
